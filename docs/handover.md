## 3. 這一段踩過的坑

- **登記冊「推薦之政黨：無」≠ 無黨籍** → build 時一律顯示「無（未經政黨推薦）」，不要在 JSON 寫成無黨籍再當黨籍用。
- **2022 年公報的「現任」字樣** → 照抄進經歷會讓落選者看起來像現任；一律標「（2022 年公報所載）」。
- **本人說法寫成報導事實** → 驗證抓到多次（減債 83 億、圖書館人次、提案 400 件）；凡是「某某表示」一律加「（本人說法）」。
- **驗證報告本身也會錯** → 例如把鄭方說法當起訴事實、說 TVBS 沒寫刪文啟事；處理驗證發現前要自己開原文確認。
- **盲測選項的機構詞洩漏身分** → 「市立」「三讀」「在議會質詢」「任內」都會指向特定候選人，改寫時要避開；「政見／過往作為」標籤也會洩漏誰是新人，已拿掉不顯示。
- **聯合報網址對程式回 404** → 不一定是撤稿，多半是擋爬蟲；用搜尋引擎確認收錄再判斷。
- **WebSearch 是整個 session 共用額度（約 200 次）** → 多個研究 agent 同時跑會用完；
  派工時給每隻上限，優先 WebFetch 已知 URL。
- **時區** → 倒數與 build 日期都用 `Asia/Taipei` 的日期，UTC 會差一天。
