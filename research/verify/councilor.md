# 縣議員候選人資料交叉驗證

驗證日期：2026-11-15。驗證對象：`research/raw/councilor.json`、
`councilor-plain-indigenous.json`、`councilor-mountain-indigenous.json`
與三份 notes，共 27 位候選人。驗證者只讀不改，修正由主對話決定。

## 結論

- 會誤導一般讀者：6 條。小瑕疵：12 條。
- 最嚴重的一條是歐陽霆唯一一筆爭議的司法狀態。JSON 寫「偵查中」，
  但三立原文只有林思銘一方說「已委任律師，依法對歐陽霆議員提起刑事
  告訴」，沒寫受理機關，也沒有任何檢方動作的報導。
- 名單核對全部通過：27 人的選區、號次、姓名、性別、出生年、推薦政黨
  都和選委會號次抽籤結果、候選人登記冊一致；現任與否和議會「現任
  議員」頁一致；第1、2選舉區的里別、應選名額、婦女保障名額，以及
  第12、13選舉區範圍，都和中選會公告一致。
- 打不開的來源：154 個不重複 URL 中，153 個 HTTP 200 且頁面標題正常；
  1 個（陳秀玲臉書粉專）對程式抓取回 HTTP 400。
- 對等性：多數人用語一致，但「本人說法」的標示不一致（邵啟月、林碩彥
  有標「據其自述」「據他轉述」，蔡蕥鍹、杜文中同性質的條目沒標）。
  另有兩位新人的資料其實在已用過的來源裡查得到，卻留空（B8、B9）。

## 核對方法

- 選委會三份 PDF（中選會選區公告、號次抽籤結果、候選人登記冊）與
  政見發表會時間地點表，用 curl 下載後以 `pdftotext -enc UTF-8` 抽文字，
  逐人比對。出生年以民國年加 1911 換算。
- 現任與否：WebFetch 開議會「現任議員」頁，第20屆竹北選區列 12 人，
  平地原住民 1 人（林秉君）、尖石區 1 人（劉建民）、五峰區 1 人
  （張益生）。
- `controversies` 共 2 條，都開原文逐句核對；歐陽霆那條另用 WebSearch
  查後續與本人回應。
- `achievements`、`platform` 每人至少抽 2 條（不足 2 條就全查）。
  議會質詢紀錄 PDF 用 pdftotext 抽全文後以關鍵字比對發言人與內容。
- notes 裡沒收進 JSON 的事件：王炳漢的 2019 鄰長買票案另用 WebSearch
  查主流媒體報導。
- 154 個 URL 全部用 curl 測 HTTP 狀態並抓頁面標題，排除假 200。
- WebSearch 用了 3 次。

## 一、會誤導一般讀者（6 條）

### A1. 歐陽霆爭議的司法狀態寫成「偵查中」

- **位置**：`councilor-12 controversies[0].status`
- **原文**：「偵查中」
- **來源實際寫什麼**：三立 2025-06-19
  <https://www.setn.com/news/1674846> 只寫林思銘表示「已委任律師，
  依法對歐陽霆議員提起刑事告訴」，主張違反個資法。報導沒寫受理的
  地檢署，也沒寫檢方是否分案。我另用 WebSearch 查，沒找到任何後續
  （起訴、不起訴、偵結）報導，也沒找到歐陽霆對提告的回應。距今已
  17 個月，「偵查中」是推測，讀者會以為檢方正在偵辦。
- **補充脈絡**：同一篇報導寫明，林思銘指控的起因是歐陽霆在罷免期間
  公開質疑他「300 張未繳罰單」與欠稅。summary 沒交代這個起因，讀者
  只看到單方指控。
- **建議改法**：status 改為「當事人稱已提告，司法進度未查得」；summary
  補一句「起因是歐陽霆在 2025 年罷免期間公開質疑林思銘的交通罰單與
  欠稅」。`candidate_response` 維持 null 即可，但網站顯示時建議寫
  「查無本人回應」。
- **嚴重度**：高（司法狀態錯）

### A2. 林秉君的政黨寫「無黨籍」

- **位置**：`councilor-pi-02 party`（`councilor-pi-01` 法隆伊佑同類）
- **原文**：「無黨籍」
- **來源實際寫什麼**：登記冊的欄位是「推薦之政黨」，林秉君這欄是
  「無」，意思是沒有政黨推薦，不等於沒有黨籍。議會個人頁黨籍寫
  中國國民黨；自由時報 2026-06-09
  <https://news.ltn.com.tw/news/HsinchuCounty/paper/1758123> 寫國民黨縣黨部
  提名名單「第十二選區林秉君」。她是否退黨，查無報導。法隆伊佑 2022
  年由民進黨推薦，目前黨籍同樣查無。
- **建議改法**：這兩人 party 改寫「無（未經政黨推薦）」，或網站欄位名稱
  改成「推薦政黨」並顯示「無」。background 已並陳三種資料，保留。
- **嚴重度**：中（政黨標示會讓讀者以為她不是國民黨員）

### A3. 蔡蕥鍹的「任內教育政績」其實是本人競選說法

  <https://udn.com/news/story/124652/9729558> 是她登記參選當天的報導，
  三項都是「她指出」，記者沒有另外查證。會考改制依 WebSearch 結果，

- **嚴重度**：中（本人說法寫成事實，可能把區域決議算到個人）

## 三、notes 裡沒收進 JSON 的事件
